# UTBL-Website
A debut website for a planned videogame I might develop in the near future titled "Until The Bleeding Edge".

While this project is initially created to fulfill the requirements of the Web Systems and Technologies course outlined in the Bachelor of Science in Computer Science program syllabus, the final website may be used as an official product in regards to promoting and introducing the "Until The Bleeding Edge" videogame.
